# 无人机射频信号轻量化识别系统 (UAV RF-Signal Lightweight Recognition System)

本项目为电子科技大学本科毕业设计成果。针对高识别精度与高边缘硬件部署代价之间的矛盾，本系统设计并实现了一种软硬协同的无人机射频信号轻量化智能识别系统。系统通过对无人机 I/Q 信号进行一维布尔特征压缩，引入基于离散命题逻辑的 Tsetlin Machine (TM) 算法实现自主分类，并最终成功在 Zynq SoC (XC7Z020) 平台完成了全链路门级电路映射与加速推理。

---

## ⚡ 核心系统架构与技术亮点

本系统彻底转变了传统的浮点计算范式，从根本上解决了边缘硬件算力与功耗的瓶颈：

1. **一维时频布尔特征压缩**：利用短时傅里叶变换 (STFT) 和数学形态学滤波对原始高维 I/Q 信号降噪，将二维时频图谱极致压缩为 128 位一维布尔向量（包含 59 位频域、64 位时域及 5 位专家统计先验位），从数据源头清除了乘法运算冗余。
2. **纯逻辑轻量化识别模型 (1D-TM)**：采用 Tsetlin Machine 作为核心分类器。在软件端完成 10 类无人机机型训练后，通过逆向剥离底层自动机收敛状态生成只读掩码（`.coe` 文件），免去了传统 CNN 漫长且易失真的网络剪枝与 INT8 量化流程。
3. **Zynq SoC 软硬协同部署**：
   * **PL 端 (FPGA)**：设计了六状态门级推理状态机和逻辑子句匹配电路，利用 BRAM 固化存储 15,000 条模型掩码，计算完全基于基础组合逻辑（AND/OR/NOT），无任何 DSP 乘法器消耗。
   * **PS 端 (ARM)**：负责离线测试数据的加载、动态“即时取反”拼接，并通过 AXI4-Lite 总线实现微秒级的软硬件协同握手与数据调度。

## 📊 实验结论与板级实测指标

在含有真实信道衰落和背景噪声的 **DroneRFa 大规模射频数据集**下，针对 10 类目标进行了全面测试：

* **分类准确率 (Accuracy)**：板级实测准确率达到 **90.88%**（与软件仿真完全一致），性能逼近重型残差网络 ResNet (91.85%)，显著优于基础 DNN (84.77%)。
* **极低资源占用**：核心推理加速引擎仅占用 XC7Z020 芯片约 **3% 的查找表 (LUT)**、1% 的触发器 (FF) 和 0.45% 的 DSP，真正实现用存储资源（76% BRAM）换取宝贵的计算资源。
* **极致低功耗**：经 Vivado 物理综合评估，PL 端逻辑动态功耗低至 **0.001W**，极其契合单兵分布式边缘无源侦测网的实战场景。
* **关键消融实验**：实验表明，若剥离 5 位“专家统计先验位”，模型整体准确率会从 **90.88% 显著回落至 87.9%**，尤其在区分底层协议高度同源的机型（如将 MATRICE 200 误判为 Phantom 4 Pro）时，专家先验位提供了至关重要的全局宏观特征补充。
